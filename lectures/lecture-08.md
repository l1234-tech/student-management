# Лекция 8. SPA-архитектура frontend-приложения

*Текстовый конспект по презентации «Лекция №8» из предоставленного архива.*

## AJAX и SPA

AJAX (Asynchronous JavaScript and XML) — подход, при котором JavaScript обменивается данными с сервером и обновляет часть интерфейса без полной перезагрузки страницы. Примеры: поиск, фильтры, пагинация, отправка форм и уведомления.

SPA (Single Page Application) — приложение, в котором загружается один основной HTML-документ, а переходы, отправка форм и подгрузка данных выполняются динамически. MPA (Multi Page Application) строится вокруг отдельных страниц, которые браузер получает как самостоятельные документы.

## Компоненты SPA

Компонент — независимый переиспользуемый блок интерфейса, обычно объединяющий шаблон, стили и код, обслуживающий шаблон. Компоненты образуют дерево и позволяют разделить интерфейс на понятные части.

В презентации выделены общие слои SPA:

- **Router** — связывает URL с компонентами страниц.
- **Pages** — компоненты верхнего уровня, соответствующие маршрутам и собирающие feature-компоненты.
- **Features** — пользовательские операции и функциональные блоки, например таблица или форма.
- **Domain model** — предметные сущности и внутренние типы.
- **API client** — сервисы HTTP-запросов и базовой обработки ответов.
- **Shared** — общие элементы, используемые разными частями приложения.

## App Shell

App Shell — архитектурный шаблон, отделяющий постоянные части интерфейса от динамического содержимого. Общая оболочка может включать шапку, меню и каркас страницы, а данные и основное содержимое загружаются отдельно.

Преимущества подхода: часть файлов можно кешировать, каркас интерфейса отображается быстрее, повторная загрузка общих ресурсов не требуется. Конкретная реализация зависит от приложения; структура из презентации — пример, а не обязательная схема.

## Связь с проектом Student Management

В лабораторной №4 Router соответствует Vue Router, Pages — каталогу `src/pages`, Features — переиспользуемым компонентам из `src/components`, API client — `src/api`, Domain model — типам/структурам данных студентов, Shared — общим компонентам и стилям.

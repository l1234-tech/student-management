## Оригинальные PDF

Загруженные в чат файлы: «Лабораторная 1.pdf», «Лаб 2.pdf», «Лабораторная 3.pdf», «Лабораторная 4.pdf».

**Статус:** содержимое ТЗ извлечено для подготовки Markdown-конспектов, но бинарные PDF ещё не загружены в этот каталог. Само создание Markdown-файла не копирует PDF. Чтобы хранить оригиналы в репозитории, загрузи файлы в docs/lab-specs/ через Git или GitHub UI и переименуй их в lab-1.pdf … lab-4.pdf. После загрузки добавь ссылки сюда.

Оригиналы и конспекты выполняют разные функции: PDF сохраняет исходную формулировку, Markdown обеспечивает поиск и удобную подготовку.

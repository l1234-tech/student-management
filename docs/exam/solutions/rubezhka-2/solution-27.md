# 27. Lifting State Up. Когда состояние стоит поднять к общему родителю?

> Развёрнутый ответ из прежнего комплекта сохранён. Формулировка сверена с оригинальным PDF. Источники: лекции №2–11 и REST.pdf ([каталог](../../../../lectures/README.md)); дополнительные пояснения к API отмечены в ответе.

Если нескольким соседним компонентам нужно согласованное значение, его переносят в ближайшего общего родителя. Родитель становится единственным владельцем этого state и передаёт детям значение и callbacks. Например, если фильтр и список должны отражать один выбранный факультет, родитель хранит фильтр и передаёт его обоим.

Поднимать состояние выше нужно ровно настолько, насколько требуется для координации. Слишком высокое состояние заставляет несвязанные части приложения зависеть от него; локальный ввод, используемый одной формой, обычно не нужно класть в глобальный store.

**Опора на лекцию:** поток данных компонентов. **Дополнение:** схема соответствует [React lifting state up](https://react.dev/learn/sharing-state-between-components).

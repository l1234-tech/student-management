# 18. Условный рендеринг и вывод списков в компонентных фреймворках. Как состояние влияет на отображение элементов? Приведите пример на выбранном фреймворке.

> Развёрнутый ответ из прежнего комплекта сохранён. Формулировка сверена с оригинальным PDF. Источники: лекции №2–11 и REST.pdf ([каталог](../../../../lectures/README.md)); дополнительные пояснения к API отмечены в ответе.

Интерфейс строится из текущего состояния: `loading` показывает индикатор, `error` — сообщение, пустой результат — подсказку, а успешный запрос — список. Условие выбирает ветку представления, а список отображает элементы коллекции.

```jsx
if (status === 'loading') return <p>Загрузка…</p>;
if (status === 'error') return <p role="alert">Не удалось загрузить список</p>;
return students.length
  ? <ul>{students.map(s => <li key={s.id}>{s.name}</li>)}</ul>
  : <p>Студенты не найдены</p>;
```

Во Vue похожий результат задают `v-if`/`v-else` и `v-for`; `v-show` меняет видимость CSS, сохраняя узел, тогда как `v-if` условно создаёт/удаляет его. Для списков нужен стабильный ключ. Разделяйте состояния загрузки, ошибки, пустого результата и готовых данных: пустой массив сам по себе не сообщает, завершился ли запрос.

**Опора на лекцию:** декларативная модель «UI = функция данных». **Дополнение:** условные конструкции конкретных фреймворков.

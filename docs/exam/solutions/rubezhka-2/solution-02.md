# 02. Императивный и декларативный подходы к построению пользовательского интерфейса.

> Развёрнутый ответ из прежнего комплекта сохранён. Формулировка сверена с оригинальным PDF. Источники: лекции №2–11 и REST.pdf ([каталог](../../../../lectures/README.md)); дополнительные пояснения к API отмечены в ответе.

Императивный код описывает последовательность команд: найти элемент, создать узел, изменить текст, скрыть кнопку, добавить обработчик. Разработчик вручную поддерживает соответствие между DOM и данными. Декларативный код описывает желаемый интерфейс для текущих данных, а библиотека применяет необходимые изменения.

```js
// Императивно
document.querySelector('#count').textContent = String(count);

// Декларативно во Vue
// <p>{{ count }}</p>
```

Декларативный стиль облегчает рассуждение о состоянии: если `count` равен 3, шаблон показывает 3. Он не отменяет императивные операции вообще: работа с Canvas, фокусом, сторонней библиотекой или браузерным API может требовать эффектов и refs. Такие операции изолируют в обработчиках и lifecycle/effect-функциях.

**Опора на лекцию:** лекция 9 прямо рассматривает декларативный и императивный подходы. **Дополнение:** примеры показывают различие на DOM и Vue-шаблоне.

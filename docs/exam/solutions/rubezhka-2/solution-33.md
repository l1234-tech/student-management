# 33. RxJS: Observable и Observer. Отличие потока событий от Promise.

> Развёрнутый ответ из прежнего комплекта сохранён. Формулировка сверена с оригинальным PDF. Источники: лекции №2–11 и REST.pdf ([каталог](../../../../lectures/README.md)); дополнительные пояснения к API отмечены в ответе.

Observable описывает поток уведомлений, а Observer задаёт обработчики `next`, `error` и `complete`. Поток может выдать ноль, одно или много значений во времени. Подписка запускает или подключает обработку; `unsubscribe()` позволяет прекратить участие и освободить ресурс.

Promise представляет один будущий результат: он завершается одним значением или ошибкой. У Promise нет встроенного метода отмены, тогда как Observable по контракту подписки можно отписать; реально ли это остановит сетевую операцию — зависит от источника и адаптера. Observable поддерживает операторы преобразования и комбинирования последовательностей, поэтому подходит для событий ввода и длительных потоков.

```ts
const observer = {
  next: value => console.log(value),
  error: error => console.error(error),
  complete: () => console.log('готово')
};
const subscription = stream$.subscribe(observer);
subscription.unsubscribe();
```

**Опора на лекцию:** RxJS. **Дополнение:** [RxJS Subscription](https://rxjs.dev/guide/subscription) и API Observables.

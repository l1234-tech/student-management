# 62. Напишите компонент-счётчик на выбранном frontend-фреймворке: реактивное значение count начинается с 0, кнопки «+1» и «Сброс» изменяют его, интерфейс показывает актуальное значение.

> Развёрнутый ответ из прежнего комплекта сохранён. Формулировка сверена с оригинальным PDF. Источники: лекции №2–11 и REST.pdf ([каталог](../../../../lectures/README.md)); дополнительные пояснения к API отмечены в ответе.

~~~vue
<script setup>
import { ref } from "vue";
const count = ref(0);

function increment() {
  count.value += 1;
}
function reset() {
  count.value = 0;
}
</script>
<template>
  <p>Счётчик: {{ count }}</p>
  <button @click="increment">+1</button>
  <button @click="reset">Сброс</button>
</template>
~~~

ref создаёт реактивное значение; в скрипте его читают/меняют через .value, в шаблоне Vue автоматически разворачивает ref. increment добавляет единицу, reset обнуляет. @click связывает событие кнопки с функцией. Изменение count автоматически обновляет интерфейс — реактивность из лекции 9.

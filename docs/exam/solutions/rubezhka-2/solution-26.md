# 26. Формы в SPA: controlled и uncontrolled inputs, обработка отправки.

> Развёрнутый ответ из прежнего комплекта сохранён. Формулировка сверена с оригинальным PDF. Источники: лекции №2–11 и REST.pdf ([каталог](../../../../lectures/README.md)); дополнительные пояснения к API отмечены в ответе.

Controlled input хранит значение в state: отображаемое значение задаётся приложением, а `onChange` обновляет state. Это удобно для мгновенной валидации, форматирования и синхронизации нескольких полей. Uncontrolled input хранит значение в DOM; приложение читает его при отправке через `FormData` или ref. Такой вариант проще для небольших форм, но хуже подходит для логики, зависящей от каждого изменения.

```jsx
function NameForm() {
  const [name, setName] = useState('');
  return <input value={name} onChange={e => setName(e.target.value)} />;
}
```

При submit остановите стандартную перезагрузку, проверьте данные, покажите loading, отправьте запрос и отобразите успех или ошибку. Серверная проверка всё равно обязательна: клиентскую валидацию можно обойти.

**Опора на лекцию:** формы и состояние компонентов. **Дополнение:** controlled/uncontrolled различие см. в [React sharing state](https://react.dev/learn/sharing-state-between-components).

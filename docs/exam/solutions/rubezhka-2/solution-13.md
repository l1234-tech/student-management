# 13. Slots, children и композиция компонентов. Зачем родителю передавать содержимое?

> Развёрнутый ответ из прежнего комплекта сохранён. Формулировка сверена с оригинальным PDF. Источники: лекции №2–11 и REST.pdf ([каталог](../../../../lectures/README.md)); дополнительные пояснения к API отмечены в ответе.

Slot/`children` позволяет компоненту-контейнеру определить общую оболочку, а родителю передать внутреннее содержимое. Контейнер знает оформление и расположение, но не обязан знать конкретную разметку содержимого. Это даёт композицию вместо множества специальных props для каждого варианта.

```vue
<!-- Card.vue -->
<template><section class="card"><slot /></section></template>

<!-- Родитель -->
<Card><h2>Студент</h2><p>Группа P3222</p></Card>
```

В React похожую роль играет `children`: `<Card><StudentDetails /></Card>`. Именованные slots подходят, когда у компонента несколько областей, например `header`, `default` и `actions`. Slot не является механизмом управления произвольным состоянием; он задаёт точку композиции содержимого.

**Опора на лекцию:** лекция 9 рассматривает slots и композицию. **Дополнение:** конкретный синтаксис — [Vue slots](https://vuejs.org/guide/components/slots.html) и [React children](https://react.dev/learn/passing-props-to-a-component).

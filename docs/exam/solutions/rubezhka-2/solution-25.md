# 25. Path- и query-параметры URL как часть состояния интерфейса.

> Развёрнутый ответ из прежнего комплекта сохранён. Формулировка сверена с оригинальным PDF. Источники: лекции №2–11 и REST.pdf ([каталог](../../../../lectures/README.md)); дополнительные пояснения к API отмечены в ответе.

Path-параметры обычно идентифицируют ресурс или маршрут: `/students/42` означает страницу студента с ID 42. Query-параметры обычно задают необязательные параметры представления/выборки: `/students?group=P3222&page=2&sort=name`.

URL удобен для состояния, которое пользователь должен сохранить, скопировать или восстановить через Back/Forward: выбранный раздел, поиск, фильтр и пагинация. Секреты и токены в URL помещать нельзя: URL может попасть в историю, журналы и заголовок Referer. Разбирайте и валидируйте параметры — текст из URL является внешним вводом.

**Опора на лекцию:** навигация SPA и REST-маршруты. **Дополнение:** синтаксис path/query определяется router и серверным API.

# План подготовки до 27 октября

## 21 октября — карта курса и Web
- [ ] Разобраться в различиях Интернет / Web / сайт / веб-приложение / API.
- [ ] Повторить клиент-серверную модель и HTTP.
- [ ] Прочитать [карту тем](syllabus.md).
- [ ] Пройти вопросы лабораторной №1.

## 22 октября — HTML, CSS, DOM, JavaScript
- [ ] HTML, семантика, формы, встроенная валидация.
- [ ] CSS, каскад, селекторы, адаптивность.
- [ ] DOM, события, функции, массивы и объекты.
- [ ] Cookies, localStorage, IndexedDB, JSON.
- [ ] Решить [практику JavaScript](practice/javascript.md).

## 23 октября — модули, async и HTTP
- [ ] ES modules: export/import.
- [ ] Promise, async/await, fetch, обработка ошибок.
- [ ] HTTP-методы, статусы, REST, path/query.
- [ ] Пройти вопросы лабораторной №2.
- [ ] Написать модули из шаблона билета самостоятельно.

## 24 октября — Backend и Java
- [ ] Слои Controller → Service → Repository.
- [ ] DTO, серверная валидация, единые ошибки.
- [ ] Java, JVM, ООП, исключения, аннотации.
- [ ] DI/IoC и внедрение через конструктор.
- [ ] Пройти [DEFENSE.md](../3%20lab/DEFENSE.md).

## 25 октября — БД, безопасность, лабораторная №4
- [ ] SQL, PK/FK, ORM/JPA, транзакции.
- [ ] Аутентификация/авторизация, JWT, access/refresh, роли.
- [ ] Компоненты, маршрутизация, глобальное состояние.
- [ ] Observable, Subscription, операторы RxJS.
- [ ] Dockerfile, multi-stage build, Nginx, Compose.

## 26 октября — пробный экзамен
- [ ] Решить 3 билета на время.
- [ ] Отвечать на теорию за 1–2 минуты на вопрос.
- [ ] Написать практику без подсказок.
- [ ] Повторить только темы, в которых ошибся.

## 27 октября — финальное повторение
- [ ] Пройти [карточки](flashcards.md) и [чек-лист](checklist.md).
- [ ] Повторить определения и типичные ошибки.
- [ ] Не начинать большой новый раздел.

## Формат занятия
25–40 минут теории → 20 минут устного объяснения → 30–45 минут практики → 5 минут фиксации ошибок.

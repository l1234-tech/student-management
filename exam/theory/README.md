# Полный теоретический конспект

Это не билеты и не краткая шпаргалка, а учебник для подготовки с нуля. Читай главы последовательно: сначала понимай термины и связи, затем разбирай код построчно и выполняй мини-проверки. Билеты и готовые ответы остаются отдельными разделами.

## Как читать главу

В каждой главе должны быть: определения, объяснение «зачем это нужно», схема работы, разобранные примеры кода, частые ошибки и вопросы для самопроверки. Примеры общего характера помечены как учебные; детали конкретной лабораторной следует сверять с её условием и исходным кодом.

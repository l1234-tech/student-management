# 4. JavaScript: основы языка

## 4.1. Что такое JavaScript

**JavaScript (JS)** — язык программирования, который в браузере используется для поведения интерфейса, обработки событий и HTTP-запросов. Он также запускается вне браузера, например в Node.js. JavaScript и Java — разные языки, несмотря на похожие названия.

JavaScript динамически типизирован: тип значения определяется во время выполнения. Переменная может в разное время ссылаться на значения разных типов, хотя обычно менять смысл переменной без необходимости не стоит.

## 4.2. Переменные: const, let и var

```js
const group = "R3222";
let count = 0;
count = count + 1;
```

- `const` запрещает повторное присваивание переменной. Если там объект или массив, его содержимое всё ещё может изменяться.
- `let` позволяет повторно присваивать значение.
- `var` — старый способ объявления с иными правилами области видимости; в современном коде обычно выбирают `const` или `let`.

**Область видимости** — место программы, где имя доступно. `let` и `const` имеют блочную область видимости: переменная, объявленная внутри `{}`, обычно не видна за пределами этого блока.

## 4.3. Типы данных

Примитивные типы:
- `string` — строка;
- `number` — число;
- `boolean` — `true` или `false`;
- `undefined` — значение не было задано;
- `null` — намеренное отсутствие значения;
- `bigint` — целые числа произвольной точности в поддерживаемом диапазоне;
- `symbol` — уникальные символы.

Объекты — отдельная категория, в которую входят обычные объекты, массивы и функции.

```js
const name = "Анна";
const age = 20;
const active = true;
const nothing = null;

console.log(typeof name);   // "string"
console.log(typeof age);    // "number"
console.log(typeof active); // "boolean"
console.log(typeof nothing); // историческая особенность: "object"
```

Для `null` оператор `typeof` возвращает `"object"` по исторической причине. Если нужно точно проверить отсутствие значения, используй `value === null`.

## 4.4. Сравнения и условия

```js
const age = 20;

if (age >= 18) {
  console.log("Совершеннолетний");
} else {
  console.log("Несовершеннолетний");
}
```

Операторы сравнения: `===`, `!==`, `>`, `<`, `>=`, `<=`. Предпочитай строгое равенство `===`, которое не выполняет неявное приведение типов.

```js
console.log(5 === "5"); // false
console.log(5 == "5");  // true: происходит преобразование типа
```

Логические операторы:
- `&&` — логическое И;
- `||` — логическое ИЛИ;
- `!` — отрицание.

**Truthy/falsy** — значения, которые в логическом контексте трактуются как истинные или ложные. К falsy относятся, например, `false`, `0`, `-0`, `""`, `null`, `undefined`, `NaN`. Пустой массив `[]` и пустой объект `{}` являются truthy.

## 4.5. Функции

Функция — именованный или безымянный блок кода, который можно вызвать. Она может принимать **параметры** и возвращать **результат** через `return`.

```js
function formatStudent(name, group) {
  return `${name} — ${group}`;
}

const result = formatStudent("Анна", "R3222");
console.log(result);
```

Параметры — имена в определении функции; аргументы — значения, передаваемые при вызове. Если функция ничего явно не возвращает, результат вызова — `undefined`.

Стрелочная функция:

```js
const double = (number) => number * 2;
console.log(double(4)); // 8
```

Когда у стрелочной функции одно выражение без фигурных скобок, оно возвращается автоматически. Если есть фигурные скобки, для возврата результата нужен `return`.

## 4.6. Массивы

Массив хранит упорядоченный набор значений. Индексация начинается с нуля.

```js
const students = ["Анна", "Иван", "Мария"];
console.log(students[0]); // Анна
console.log(students.length); // 3
```

Частые методы:
- `push(value)` добавляет в конец;
- `pop()` удаляет последний элемент;
- `map(fn)` создаёт новый массив из результатов функции;
- `filter(fn)` создаёт массив элементов, прошедших условие;
- `find(fn)` возвращает первый подходящий элемент или `undefined`;
- `forEach(fn)` выполняет действие для каждого элемента.

```js
const students = [
  { id: 1, name: "Анна", active: true },
  { id: 2, name: "Иван", active: false }
];

const names = students.map((student) => student.name);
const activeStudents = students.filter((student) => student.active);
```

`map` удобно использовать для преобразования, `filter` — для отбора. Не используй `map`, если не нужен новый массив и требуется только побочный эффект.

## 4.7. Объекты

Объект хранит свойства в форме ключ-значение.

```js
const student = {
  id: 42,
  name: "Анна",
  group: "R3222"
};

console.log(student.name);
console.log(student["group"]);
```

Доступ возможен через точку или квадратные скобки. Квадратные скобки полезны, если имя свойства хранится в переменной или содержит специальные символы.

```js
const key = "name";
console.log(student[key]); // Анна
```

**Деструктуризация** извлекает значения в отдельные переменные:

```js
const { id, name } = student;
```

**Spread-оператор** `...` позволяет поверхностно копировать или объединять объекты/массивы:

```js
const updatedStudent = { ...student, group: "Р3222" };
```

Это поверхностная копия: вложенные объекты по-прежнему могут ссылаться на те же объекты в памяти.

## 4.8. Ссылки и мутация

Примитивные значения присваиваются как значения; объекты и массивы доступны через ссылки. Поэтому:

```js
const first = { name: "Анна" };
const second = first;
second.name = "Мария";

console.log(first.name); // Мария
```

Обе переменные ссылаются на один объект. Изменение содержимого объекта называется **мутацией**. В приложениях с состоянием важно понимать, когда объект меняется на месте, а когда создаётся новый.

## 4.9. Обработка ошибок

```js
try {
  const data = JSON.parse('{"name":"Анна"}');
  console.log(data.name);
} catch (error) {
  console.error("Не удалось разобрать JSON", error);
}
```

- `try` — код, в котором ожидается возможная ошибка;
- `catch` — обработчик перехваченной ошибки;
- `throw` — выбрасывает ошибку и прерывает обычное выполнение текущего пути.

Ошибки не следует просто подавлять: нужно либо обработать их, либо передать выше так, чтобы вызывающий код мог принять решение.

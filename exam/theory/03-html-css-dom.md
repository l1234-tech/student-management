# 3. HTML, CSS, DOM и браузер

## 3.1. HTML — структура документа

**HTML (HyperText Markup Language)** — язык разметки. Он задаёт структуру документа и смысл его частей, а не является языком программирования общего назначения.

Пример:

```html
<!doctype html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Студенты</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <main>
    <h1>Список студентов</h1>
    <button id="reload">Обновить</button>
    <ul id="students"></ul>
  </main>
  <script type="module" src="main.js"></script>
</body>
</html>
```

Разбор:
- `<!doctype html>` включает стандартный режим обработки HTML.
- `<html lang="ru">` — корневой элемент; `lang` сообщает язык документа.
- `<head>` содержит метаданные, заголовок, ссылки на стили.
- `<body>` содержит видимое содержимое страницы.
- `<main>` обозначает основное содержимое.
- `<h1>` — заголовок верхнего уровня.
- `id` даёт элементу уникальный идентификатор внутри документа.
- `<script type="module">` подключает JavaScript-модуль.

**Тег** — запись разметки, например `<p>`. **Элемент** — узел документа, образованный тегом и его содержимым. **Атрибут** — дополнительная информация внутри открывающего тега, например `id="reload"`.

## 3.2. Семантическая разметка

Семантический HTML использует элементы по назначению:

- `<header>` — вводная часть страницы или раздела;
- `<nav>` — навигация;
- `<main>` — основное содержимое;
- `<section>` — тематический раздел;
- `<article>` — самостоятельная публикация или блок;
- `<footer>` — заключительная часть;
- `<button>` — действие;
- `<a href="...">` — переход по ссылке;
- `<label>` — подпись поля формы.

Семантика улучшает доступность, поддержку вспомогательных технологий и понятность кода. Не следует использовать кнопку только ради внешнего вида, если по смыслу нужен переход по ссылке.

## 3.3. Формы и ввод

```html
<form id="student-form">
  <label for="student-name">Имя</label>
  <input id="student-name" name="name" required minlength="2">
  <button type="submit">Сохранить</button>
</form>
```

- `form` объединяет поля и отправку формы.
- `label for` связывает подпись с полем по совпадающему `id`.
- `name` задаёт имя поля при стандартной отправке формы.
- `required` включает проверку обязательности в браузере.
- `minlength` задаёт минимальную длину строки.

HTML-валидация полезна для пользователя, но не заменяет проверку на backend. Клиентские атрибуты можно обойти.

## 3.4. CSS — оформление

**CSS (Cascading Style Sheets)** описывает внешний вид: цвета, размеры, отступы, расположение элементов, адаптивность и анимацию.

```css
body {
  font-family: sans-serif;
  margin: 0;
  padding: 24px;
}

#students {
  display: grid;
  gap: 12px;
}

.student-card {
  border: 1px solid #ccc;
  border-radius: 8px;
  padding: 16px;
}
```

Селекторы:
- `body` — элемент по имени;
- `#students` — элемент по идентификатору;
- `.student-card` — элементы по классу.

CSS-правило состоит из селектора и блока объявлений. Свойство — например `padding`; значение — например `16px`.

## 3.5. Каскад, специфичность и наследование

CSS означает Cascading — каскад. Если несколько правил подходят элементу, браузер определяет, какое значение использовать, учитывая происхождение и важность объявления, специфичность селектора и порядок правил.

Упрощённо, селектор с `#id` обычно специфичнее селектора класса, а селектор класса — селектора тега. Но не пытайся исправлять всё бесконечным добавлением `!important`: лучше упростить стили и избежать конфликтов.

**Наследование** — некоторые свойства, например `color` и `font-family`, могут передаваться от родителя к потомкам. Многие свойства, например `margin`, автоматически не наследуются.

## 3.6. Блочная модель

Каждый обычный элемент можно представить как прямоугольник:

1. **Content** — содержимое.
2. **Padding** — внутренний отступ между содержимым и рамкой.
3. **Border** — рамка.
4. **Margin** — внешний отступ от соседних элементов.

```css
* {
  box-sizing: border-box;
}
```

При `border-box` указанная ширина включает content, padding и border, что часто упрощает расчёты размеров.

## 3.7. Flexbox и Grid

**Flexbox** — модель компоновки преимущественно вдоль одной оси. Удобна для строк кнопок, панелей и выравнивания элементов.

```css
.toolbar {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 12px;
}
```

**CSS Grid** — двумерная сетка строк и столбцов. Подходит для карточек и сложных макетов.

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 16px;
}
```

Flexbox и Grid не конкурируют напрямую: выбирай модель по структуре задачи.

## 3.8. Адаптивная вёрстка

Адаптивность — способность интерфейса удобно работать на разных размерах экрана. Используются гибкие единицы, ограничения ширины, Flexbox/Grid и media queries.

```css
.container {
  width: min(100% - 32px, 1000px);
  margin-inline: auto;
}

@media (max-width: 600px) {
  .toolbar {
    flex-direction: column;
    align-items: stretch;
  }
}
```

`@media` применяет правила при заданных условиях. Не стоит жёстко задавать всем блокам ширину в пикселях: это может вызвать горизонтальную прокрутку на телефонах.

## 3.9. DOM

**DOM (Document Object Model)** — объектное представление HTML-документа, доступное JavaScript. Браузер создаёт дерево узлов, и скрипт может находить элементы, менять текст, атрибуты, классы и добавлять новые узлы.

```js
const heading = document.querySelector("h1");
heading.textContent = "Студенты группы Р3222";

const list = document.querySelector("#students");
const item = document.createElement("li");
item.textContent = "Анна";
list.append(item);
```

- `document` представляет документ.
- `querySelector` возвращает первый элемент, подходящий CSS-селектору, или `null`.
- `textContent` устанавливает текстовое содержимое.
- `createElement` создаёт новый элемент.
- `append` добавляет узел в конец родителя.

Если селектор ничего не нашёл, вызов свойства у `null` вызовет ошибку. Поэтому при необходимости нужно проверить наличие элемента.

Для пользовательского текста предпочитай `textContent`, а не вставку через `innerHTML`: небезопасная вставка HTML из недоверенных данных может создать XSS-уязвимость.

## 3.10. События

**Событие** — сигнал о действии или изменении: клик, ввод текста, отправка формы, загрузка страницы.

```js
const button = document.querySelector("#reload");

button.addEventListener("click", () => {
  console.log("Кнопка нажата");
});
```

`addEventListener` регистрирует обработчик. Функция вызывается, когда происходит событие. Для формы часто используют событие `submit`; чтобы не перезагружать страницу при собственной обработке, вызывают `event.preventDefault()`.

```js
const form = document.querySelector("#student-form");

form.addEventListener("submit", (event) => {
  event.preventDefault();
  const name = document.querySelector("#student-name").value.trim();
  console.log(name);
});
```

`value` содержит значение поля ввода, а `trim()` убирает пробельные символы с краёв строки.

# Практика: HTTP и REST

## Задача 1. Выбери метод
Подбери HTTP-метод для списка студентов, получения студента по ИСУ, создания, частичного изменения и удаления записи.

## Задача 2. Path или query
Объясни назначение:
- /api/students/123456
- /api/students?group=M3301
- /api/students?page=2&size=20

## Задача 3. Статус ответа
Подбери статус для чтения, создания, удаления без тела, отсутствующего ресурса, конфликта уникальности и невалидного ввода. Политика API должна быть последовательной и документированной.

## Задача 4. Stateless
Объясни stateless для API и почему это не означает, что сервер не хранит базу данных.

## Задача 5. Единый формат ошибок
Предложи JSON ошибки с кодом, сообщением и деталями валидации. Почему клиент не должен полагаться только на текст сообщения?

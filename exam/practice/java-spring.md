# Практика: Java и Spring

## Задача 1. DI
Перепиши сервис, который самостоятельно создаёт репозиторий, чтобы репозиторий передавался через конструктор. Объясни преимущества и роль контейнера Spring.

## Задача 2. Разделение слоёв
Разнеси ответственность: кто принимает HTTP, где проверяются бизнес-правила, кто обращается к БД?

## Задача 3. DTO и Entity
Почему API не обязательно должно напрямую возвращать JPA Entity? Назови риски и роль DTO/mapper.

## Задача 4. Доступ по ролям
USER может читать, ADMIN — читать и изменять. Где выполняется проверка и почему скрытия кнопки во frontend недостаточно?

## Задача 5. Транзакции
Объясни разницу между SQL-записью, flush и commit. Что должно произойти при ошибке до завершения транзакции?

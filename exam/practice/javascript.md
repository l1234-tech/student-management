# Практика: JavaScript, async/await и модули

## Задача 1. API-модуль
Создай api.js с экспортируемой async-функцией loadStudents(). Она делает GET-запрос /api/students, при неуспешном HTTP-статусе бросает ошибку, иначе возвращает JSON.

## Задача 2. Точка входа
Создай main.js, который импортирует loadStudents() и выводит список в консоль. Добавь обработку ошибки.

## Задача 3. Фильтрация массива
Дан массив студентов с полями name и group. Напиши функцию, которая возвращает студентов заданной группы, не меняя исходный массив.

## Задача 4. HTTP-ошибка
Почему fetch() обычно не отклоняет Promise только потому, что сервер вернул 404? Добавь проверку response.ok.

## Задача 5. DOM
Напиши submit-обработчик, который предотвращает перезагрузку страницы, читает значения формы и показывает результат.

## Задача 6. Устаревший поиск
Как избежать ситуации, когда медленный старый запрос перезаписывает результаты нового? Рассмотри AbortController в обычном JS и подходящий оператор RxJS.

## Критерии задачи 1–2
- loadStudents экспортируется именованным экспортом.
- Используется await fetch("/api/students").
- До чтения JSON проверяется response.ok.
- При ошибке бросается Error с HTTP-статусом.
- main.js импортирует функцию и ловит ошибку.
- Среда поддерживает ES-модули: например, script type="module" в браузере.

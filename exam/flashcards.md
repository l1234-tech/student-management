# Карточки для повторения

Закрой правую колонку и ответь вслух.

| Вопрос | Краткий ответ |
|---|---|
| HTML / CSS / JS? | Структура / оформление / поведение. |
| Что такое DOM? | Объектное представление документа, доступное из JS. |
| Что такое JSON? | Текстовый формат представления данных. |
| JSON.stringify? | Преобразует значение JS в JSON-строку. |
| JSON.parse? | Разбирает JSON-строку в значение JS. |
| CRUD? | Create, Read, Update, Delete. |
| Path-параметр? | Часть пути, часто идентификатор ресурса. |
| Query-параметр? | Параметр после вопросительного знака: фильтр, пагинация и т. п. |
| Stateless? | Запрос не зависит от неявного состояния предыдущего запроса этого клиента. |
| DTO? | Структура для передачи данных через границу приложения. |
| DI? | Передача зависимостей объекту извне. |
| IoC? | Передача управления инфраструктуре/контейнеру. |
| JPA? | Java API/спецификация для ORM. |
| EclipseLink? | Реализация JPA, ORM-провайдер. |
| Аутентификация? | Установить личность пользователя. |
| Авторизация? | Определить разрешённые действия. |
| Подписанный JWT зашифрован? | Не обязательно; payload может быть читаемым. |
| Access vs refresh? | Access обращается к API; refresh используется для обновления токенов. |
| Observable? | Поток значений во времени в RxJS. |
| Subscription? | Управление подпиской; позволяет отписаться. |
| Docker image vs container? | Образ — шаблон; контейнер — запущенный экземпляр. |
| Docker Compose? | Описание совместного запуска сервисов. |
| Почему недостаточно frontend-роли? | Запрос можно отправить напрямую; backend обязан проверить доступ. |

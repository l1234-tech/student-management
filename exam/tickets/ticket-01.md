## 2. Термины Web
Почему Интернет, Web, сайт, веб-приложение и API не являются синонимами? Объясните различия через участников и цель взаимодействия.

## 3. Практика: ES-модули
Напишите два модуля:
- api.js с экспортируемой асинхронной loadStudents(), которая запрашивает /api/students и возвращает JSON;
- main.js, который импортирует функцию и выводит результат в консоль.

При неуспешном HTTP-статусе должна возникать ошибка.

Тренировка: 20–30 минут. Не открывайте решение до завершения.

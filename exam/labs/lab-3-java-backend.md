## Ключевые объяснения
- DI передаёт зависимости объекту извне; контейнер Spring связывает компоненты. Конструктор делает зависимости явными и облегчает тестирование.
- Слои: Controller принимает HTTP; Service содержит бизнес-правила; Repository обращается к данным.
- DTO — контракт API; Entity — модель хранения. Их разделение не позволяет случайно раскрывать внутреннюю структуру БД.
- Аутентификация устанавливает личность, авторизация определяет права. Проверка роли должна быть на backend.
- Подписанный JWT не обязательно зашифрован; его содержимое может быть читаемым. Пароли в JWT хранить нельзя.
- JPA — API/спецификация, EclipseLink — ORM-провайдер, PostgreSQL — СУБД.
- Flush не равен commit; транзакция управляет согласованной фиксацией/откатом операций.

# Лабораторная №4 — Frontend на JavaScript-фреймворке

Источник: ТЗ «Лабораторная работа №4. Frontend на JavaScript-фреймворке».

## Цель

Перенести frontend системы управления студентами из лабораторной №1 на современный JavaScript-фреймворк, сохранив функциональность и добавив авторизацию, роли, управление состоянием и реактивное программирование. Клиент взаимодействует с REST API лабораторной №3.

Варианты из ТЗ: React, Vue, Angular, Svelte. RxJS обязателен для всех вариантов. В этом проекте выбран Vue 3.

## Функциональность

- Просмотр списка студентов и подробной информации.
- Создание, редактирование и удаление записей.
- Поиск, фильтрация по всем полям, сортировка и пагинация.
- Регистрация, вход, выход и просмотр текущего пользователя.
- JWT access/refresh.
- Разграничение доступа по ролям.
- Обновление интерфейса без полной перезагрузки.

## Обязательные страницы

- `/login` — авторизация.
- `/register` — регистрация.
- `/profile` — профиль пользователя.

## Архитектура

Требуются компоненты фреймворка, локальное состояние, props/inputs, hooks/lifecycle, условный рендеринг и клиентская маршрутизация. Необходимо глобальное состояние: для Vue — Pinia. RxJS должен практически применяться для реактивной обработки событий и асинхронных данных; простого импорта библиотеки недостаточно.

Клиент должен корректно обрабатывать ошибки авторизации, недостаток прав, истечение токенов, валидацию, отсутствие данных, недоступность сервера и внутренние ошибки. Для асинхронных операций отображается загрузка; повторная отправка формы блокируется на время запроса.

## Контейнеризация

Frontend и backend лабораторной №3 запускаются совместно через Docker Compose. Нужны Dockerfile, multi-stage build, Nginx или аналог для раздачи frontend, проксирование REST API, внешняя конфигурация, `.env.example` и README. ТЗ требует запуск `docker compose up --build`.

## Как заниматься
1. Прочитай тему и объясни её без конспекта.
2. Найди пример в коде проекта.
3. Ответь на контрольные вопросы вслух.
4. Реши практику без подсказки.
5. Сверься с решением и запиши ошибки.

Источники разделены: ТЗ определяет требования, [лекции](../lectures/README.md) — теоретическую основу, код репозитория — конкретную реализацию. Примеры в конспектах не означают, что функция уже реализована в проекте.

Для лабораторной №4 конкретный фреймворк пока не выбран; сначала изучаем общие требования, отдельно отмечая различия React, Vue, Angular и Svelte.

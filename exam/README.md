## Как устроены билеты

Каждый из 30 файлов в `solutions/rubezhka-1/` соответствует нумерации исходного PDF: два теоретических вопроса и одно практическое задание. Формулировки берутся из PDF; после каждого условия сначала дан прямой ответ, затем подробное объяснение теории и разбор кода.

Примеры показывают решение задания, но не означают автоматически, что соответствующая функция уже реализована в проекте. Для точного соответствия лабораторной отдельно сверяй примеры с реальным кодом и версиями библиотек.

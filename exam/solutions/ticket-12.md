# Решение билета №12

## 1. Образы и контейнеры
Docker image — неизменяемый шаблон файловой системы и конфигурации. Container — экземпляр образа с запущенным процессом и изолированным окружением.

## 2. Multi-stage и Compose
Multi-stage build разделяет этап сборки и финальный runtime-образ, уменьшая лишние инструменты в финальном образе. Nginx может раздавать собранные статические файлы и проксировать API. Docker Compose описывает сервисы, сети, переменные окружения и зависимости запуска.

## 3. Практика
Типичная схема включает frontend (собирается и раздаётся Nginx), backend (Java-приложение) и PostgreSQL. Параметры подключения и секреты передаются через переменные окружения; в репозитории хранится только .env.example без реальных секретов. Frontend обращается к backend по корректно настроенному API-маршруту.

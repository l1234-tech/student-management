## Теория 1. DOM, HTML и BOM

HTML — исходная разметка документа. Браузер разбирает её и строит DOM — объектное дерево, которое представляет элементы и текст документа. JavaScript может менять DOM: создавать элементы, менять текст и атрибуты, удалять узлы. Поэтому не нужно каждый раз загружать новый HTML-файл, если достаточно обновить часть страницы.

BOM (Browser Object Model) — набор браузерных объектов, связанных с окружением вкладки, например `window`, `location`, `history`, `navigator`. DOM относится к документу, BOM — к возможностям окна/браузера. На практике `window.document` даёт доступ к DOM.

В лабораторной №1 таблица студентов формируется из данных через JavaScript: код создаёт строки и ячейки и добавляет их в таблицу.

## Теория 2. События, обработчики и состояние

Событие — факт взаимодействия или изменения, например `click`, `input`, `submit). Обработчик — функция, которая вызывается при событии. Он читает актуальные данные, проверяет их, обновляет модель приложения и затем обновляет DOM.

Надёжный подход: данные являются источником истины, а интерфейс отражает их состояние. Если изменить только текст кнопки, не обновив объект/массив студентов, следующая отрисовка может вернуть старый текст. При удалении запись должна исчезнуть из источника данных, а затем список следует отрисовать снова.

В форме важно отменить стандартную отправку, если приложение само обрабатывает событие: `event.preventDefault()`. После валидации данные собираются, сохраняются или отправляются на API, и UI отражает результат.

## Практика. HTML-форма

```html
<form action="/api/students" method="post">
  <label for="isu-id">ИСУ ID</label>
  <input id="isu-id" name="isu_id" type="number" min="1" step="1" required>

  <label for="group">Группа</label>
  <input id="group" name="group" type="text" required>

  <label for="is-foreign">Иностранец</label>
  <input id="is-foreign" name="is_foreign" type="checkbox">

  <button type="submit">Добавить студента</button>
</form>
```

Каждый `label` связан с полем через одинаковые `for` и `id`. Для ИСУ задано положительное целое значение: `min="1"`, `step="1"` и `required`. Checkbox передаёт признак, а не обычный текст.

Важное уточнение: обычная HTML-форма отправляет поля как form data, а не JSON. Если API требует именно JSON, JavaScript должен перехватить submit, прочитать значения и выполнить `fetch` с `Content-Type: application/json`. Независимо от клиентской проверки, сервер обязан повторно валидировать входные данные.

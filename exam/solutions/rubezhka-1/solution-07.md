## Теория 1. Роли HTML, CSS и JavaScript

HTML определяет структуру и смысл: таблица, форма, поля, кнопки. CSS отвечает за визуальное оформление и адаптивность: цвета, размеры, сетки, состояния фокуса. JavaScript задаёт поведение: обработка кликов, валидация, изменение DOM, сохранение данных и HTTP-запросы.

CSS может показать, что поле выглядит ошибочным, но не должен быть единственным механизмом проверки корректности. Оформление не предотвращает прямой HTTP-запрос и не гарантирует, что значение соответствует бизнес-правилам. Корректная архитектура отделяет визуальное представление от логики проверки и от серверного контроля.

В лабораторной №1 JavaScript связывает форму с функцией валидации и обновляет список студентов; в лабораторной №2 аналогичные проверки выполняются на backend.

## Теория 2. CSS-переменные и псевдоклассы

CSS custom properties позволяют определить дизайн-токены один раз, например `--accent`, и использовать их во многих компонентах. При смене темы достаточно изменить значение переменной, а не искать каждый цвет по файлам. Псевдоклассы выражают состояние элемента: `:hover` — наведение, `:focus` — фокус, `:focus-visible` — заметный фокус для подходящего способа ввода, `:disabled` — отключённый элемент.

Так интерфейс получает единые состояния и становится проще в поддержке. Важно не полагаться только на цвет для передачи ошибки: полезно добавлять текст сообщения или другой доступный индикатор.

## Практика. Счётчик по нажатию кнопки

```html
<button id="add" type="button">Увеличить</button>
<output id="value">0</output>
<script>
  const counter = {
    value: 0,
    inc() {
      this.value += 1;
    }
  };

  const button = document.getElementById("add");
  const output = document.getElementById("value");

  button.addEventListener("click", () => {
    counter.inc();
    output.textContent = String(counter.value);
  });
</script>
```

Метод `inc` увеличивает состояние объекта. Обработчик вызывает метод, а затем обновляет отображение из актуального значения. Важно: если передать `counter.inc` отдельно как callback, контекст `this` может потеряться; здесь метод вызывается как `counter.inc()`, поэтому `this` ссылается на `counter`.

# Рубежка №1 — билет 7: точные условия и подробные решения

## Теоретический вопрос 13 — условие из файла

> Чем отличаются обязанности HTML, CSS и JavaScript при построении интерактивной страницы? Почему не стоит переносить всю проверку корректности формы в оформление CSS?

### Подробный ответ

HTML задаёт структуру и смысл страницы: формы, подписи, таблицы, кнопки и поля. CSS определяет внешний вид и адаптивность — цвета, размеры, сетки, состояния фокуса и disabled. JavaScript обеспечивает поведение: обрабатывает события, выполняет дополнительные проверки, изменяет DOM, вызывает API и обновляет состояние интерфейса.

CSS может визуально отметить поле, например классом ошибки, но оформление само по себе не проверяет бизнес-правило и не предотвращает запрос к backend. Пользователь может отключить стили, изменить DOM или послать запрос вручную. Поэтому проверка должна находиться в логике приложения, а сервер обязан проверить данные независимо от клиента.

**Прямой ответ:** HTML описывает, CSS оформляет, JavaScript добавляет поведение; CSS не является полноценной системой валидации и не может заменить серверный контроль.

## Теоретический вопрос 14 — условие из файла

> Почему CSS-переменные и псевдоклассы позволяют сделать интерфейс сопровождаемее? Объясните на примере единой цветовой схемы и реакции на :focus либо :disabled.

### Подробный ответ

CSS-переменные (custom properties) позволяют определить единые дизайн-токены, например `--accent`, `--surface` или `--text-color`, в одном месте. Если цвет кнопок или элементов темы меняется, не нужно исправлять десятки повторяющихся значений — достаточно поменять переменную.

Псевдоклассы описывают состояние элемента:
- `:hover` — указатель находится над элементом;
- `:focus` — элемент получил фокус;
- `:focus-visible` — фокус следует явно показать, например при клавиатурной навигации;
- `:disabled` — элемент отключён и не должен быть доступен для взаимодействия обычным способом.

Общий стиль для `:disabled` помогает не дублировать оформление каждой отключённой кнопки; `:focus-visible` обеспечивает заметную клавиатурную навигацию. Это повышает согласованность интерфейса, упрощает изменение темы и поддерживает доступность.

## Практическое задание 7 — условие из файла

> На JavaScript создайте объект counter с полем value и методом inc(). Привяжите его к кнопке с id add так, чтобы каждый клик увеличивал counter.value на единицу.

### Решение

```html
<button id="add" type="button">Увеличить</button>
<output id="value">0</output>

<script>
  const counter = {
    value: 0,
    inc() {
      this.value += 1;
    }
  };

  const button = document.getElementById("add");
  const output = document.getElementById("value");

  button.addEventListener("click", () => {
    counter.inc();
    output.textContent = String(counter.value);
  });
</script>
```

### Подробный разбор

- `counter.value` — состояние счётчика.
- `inc()` — метод, увеличивающий состояние на единицу.
- `addEventListener("click", ...)` регистрирует обработчик нажатия.
- `counter.inc()` вызывается как метод объекта, поэтому `this` внутри метода указывает на `counter`.
- После изменения значения выводится актуальный результат через `textContent`.

Сам объект не обязан знать о DOM: метод инкремента меняет данные, а обработчик обновляет отображение. Такое разделение облегчает тестирование и уменьшает связанность логики счётчика с интерфейсом.

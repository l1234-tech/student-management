## Теория 1. ES-модули

Один большой `script.js` смешивает обработчики интерфейса, валидацию, запросы, отображение и хранение. По мере роста сложнее находить ошибки, переиспользовать код и проверять его отдельно.

ES-модули разделяют код на файлы с явными экспортами и импортами. `export` делает выбранные функции/значения доступными другим модулям; `import` показывает зависимость. Каждый модуль имеет собственную область видимости, что уменьшает случайное загрязнение глобального пространства имён.

Например, можно выделить `validation.js`, `student-api.js` и `render-students.js`. Это логически соответствует разделению ответственности: проверка данных отдельно от HTTP и отображения. Наличие нескольких файлов полезно только если границы модулей осмысленны.

## Теория 2. Заголовки, тело, Content-Type и JSON

Заголовки описывают запрос и его контекст: `Accept` — желаемый формат ответа, `Content-Type` — формат тела запроса, `Authorization` — данные аутентификации, `Cookie` — cookies, `Cache-Control` — правила кеширования. Тело содержит передаваемые данные, например JSON с полями нового студента.

`JSON.stringify(object)` превращает объект JavaScript в JSON-строку. `Content-Type: application/json` сообщает серверу, как интерпретировать тело. Ответ читают как `await response.json()`, если тело действительно JSON. `fetch` не считает HTTP-статусы 4xx/5xx исключениями автоматически — код должен проверять `response.ok`.

## Практика. Параллельная загрузка данных

```js
async function loadPageData() {
  const [students, dormitories] = await Promise.all([
    loadStudents(),
    loadDormitories()
  ]);
  return { students, dormitories };
}
```

Обе функции вызываются до ожидания общего результата, поэтому операции выполняются параллельно настолько, насколько это поддерживают сами Promise. `Promise.all` завершится, когда завершатся оба Promise; если один отклонится, возвращённый Promise также отклонится. Ошибку здесь не подавляем, как требует условие.

Не следует писать последовательно `await loadStudents(); await loadDormitories();`, если результаты независимы: это может увеличить общее время ожидания.

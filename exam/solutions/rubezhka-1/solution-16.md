## Теория 1. Race condition при записи JSON

Race condition возникает, когда результат зависит от непредсказуемого порядка параллельных операций. Два потока могут одновременно прочитать одно старое состояние, каждый добавить свою запись, а затем записать результат. Последняя запись затрёт изменения первого потока.

Операция «прочитать → изменить → записать» не атомарна целиком, даже если чтение и запись по отдельности успешно завершаются. Для учебного приложения можно сериализовать доступ через Lock, но для многопроцессного или многосерверного приложения обычно лучше использовать БД с транзакциями и ограничениями целостности. Обычный threading.Lock не синхронизирует разные процессы.

## Теория 2. Request context и глобальные переменные

Глобальная переменная принадлежит процессу приложения, а не отдельному HTTP-запросу. Если хранить в ней текущего пользователя или данные запроса, параллельные запросы могут перезаписать значение друг друга. При нескольких воркерах каждый процесс вообще имеет собственную память.

Request context — контекст, связанный с конкретным запросом: параметры, заголовки, пользователя, трассировку. Фреймворки дают механизмы доступа к этому контексту и связывают его с текущим обработчиком/задачей. Долговременные данные нужно хранить в БД или другом общем хранилище, а не в глобальном поле «текущий запрос».

## Практика. multiprocessing и глобальный счётчик

```python
import multiprocessing

counter = 0

def increment():
    global counter
    counter += 1

if __name__ == "__main__":
    processes = [
        multiprocessing.Process(target=increment),
        multiprocessing.Process(target=increment)
    ]
    for process in processes:
        process.start()
    for process in processes:
        process.join()
    print(counter)
```

В обычной модели multiprocessing дочерние процессы имеют отдельные адресные пространства. Поэтому изменения их локальных копий глобальной переменной не меняют переменную родителя; родитель напечатает `0`. Для общего значения нужно явно использовать shared memory, `Value`, Manager или другой IPC-механизм и корректную синхронизацию.

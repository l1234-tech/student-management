## Теория 1. var, let и const

`var` имеет функциональную область видимости (или глобальную вне функции) и допускает повторное объявление в той же области. Его объявление поднимается; до присваивания значение обычно `undefined`.

`let` и `const` имеют блочную область видимости. Они доступны только после точки объявления (до этого действует temporal dead zone). `let` можно переназначить, `const` нельзя переназначить после инициализации.

`const` фиксирует ссылку/значение переменной, но не делает вложенный объект неизменяемым:
```js
const student = { group: "M3301" };
student.group = "R3222"; // разрешено
// student = {}; // TypeError
```
Чтобы запретить изменение свойств поверхностно, можно применить `Object.freeze`, но он не обеспечивает глубокую неизменяемость вложенных объектов.

Для современных учебных примеров обычно предпочитают `const` по умолчанию и `let`, если переменную нужно переназначать.

## Теория 2. Семантическая HTML-разметка

Множество `div` может визуально выглядеть так же, как семантическая разметка, если стили одинаковы. Но `div` не объясняет роль содержимого. Семантические элементы делают структуру понятнее разработчикам, браузерным инструментам и вспомогательным технологиям.

- `header` — вводная/шапка страницы или раздела.
- `nav` — блок навигационных ссылок.
- `main` — основное уникальное содержимое страницы.
- `footer` — заключительная информация о странице/разделе.

Семантика улучшает доступность и сопровождение. Она не заменяет CSS: внешний вид всё равно задаётся стилями.

## Практика. CSS-кнопка с переменной, hover и keyboard focus

```css
:root {
  --accent: #6d4aff;
}

.save-btn {
  background-color: var(--accent);
  color: white;
  border: 0;
  padding: 0.6rem 1rem;
  border-radius: 0.4rem;
}

.save-btn:hover {
  text-decoration: underline;
}

.save-btn:focus-visible {
  outline: 3px solid #222;
  outline-offset: 3px;
}
```

CSS-переменная задаётся на `:root`, поэтому доступна по всему документу. `var(--accent)` использует единый цвет. `:hover` отвечает за наведение указателя. `:focus-visible` показывает заметный фокус, в частности при клавиатурной навигации. Не стоит убирать outline без равноценной замены: это ухудшает доступность.

## Теория 1. Lock, RLock, Semaphore, Event и Queue

- `Lock` — взаимное исключение: в критическую секцию одновременно входит один поток.
- `RLock` — reentrant lock: один и тот же поток может захватить блокировку повторно, не заблокировав сам себя.
- `Semaphore` — ограничивает число одновременных доступов к ресурсу.
- `Event` — сигнал состояния: один поток устанавливает событие, другие ждут.
- `Queue` — потокобезопасная очередь для передачи задач/данных между производителями и потребителями.

Queue предпочтительнее общего списка, потому что предоставляет операции put/get и координацию потоков, уменьшает необходимость самостоятельно синхронизировать каждую операцию. Для составной операции «прочитать — изменить — записать» одной потокобезопасности отдельных операций недостаточно.

## Теория 2. Framework и HTTP-сервер

Flask, DRF и FastAPI — веб-фреймворки, которые дают маршрутизацию, обработку запросов, сериализацию/валидацию и интеграцию с приложением. HTTP-сервер принимает сетевые соединения и передаёт запросы приложению согласно интерфейсу/протоколу развёртывания. Например, приложение ASGI часто запускают за ASGI-сервером; Django/WSGI — через совместимый WSGI-сервер.

Встроенный dev-сервер полезен для разработки, но production обычно требует продуманного запуска, таймаутов, логирования, количества воркеров, TLS/reverse proxy и мониторинга. Фреймворк не отменяет инфраструктуру развёртывания.

## Практика. FastAPI POST с 201 и 409

```python
from fastapi import FastAPI, HTTPException, status
from pydantic import BaseModel

app = FastAPI()

class StudentIn(BaseModel):
    isu_id: int
    group: str

@app.post("/students", status_code=status.HTTP_201_CREATED)
def create_student(data: StudentIn):
    if repo.exists(data.isu_id):
        raise HTTPException(
            status_code=409,
            detail="Student with this ISU ID already exists"
        )
    created = repo.create(data.model_dump())
    return created
```

Pydantic-модель задаёт структуру входа; FastAPI валидирует запрос. Проверка уникальности — бизнес-правило. Конфликт возвращает 409, успешное создание — 201. В Pydantic v1 вместо `model_dump()` используется `dict()`; конкретный вызов зависит от версии. В настоящем хранилище уникальность желательно также закрепить ограничением на уровне БД/репозитория, потому что между exists и create возможна гонка.

## Прямые теоретические ответы

**Прямой ответ на вопросы 29–30.** `Lock` защищает критическую секцию взаимным исключением; `RLock` допускает повторный захват тем же потоком; `Semaphore` ограничивает число одновременных пользователей ресурса; `Event` передаёт сигнал ожидания; `Queue` безопасно передаёт элементы между производителем и потребителем. Queue обычно удобнее общего списка, потому что синхронизация и очередность передачи уже реализованы и не приходится самостоятельно защищать операции добавления/изъятия.

Flask, DRF и FastAPI — фреймворки приложения, а не весь production HTTP-стек. HTTP-сервер/ASGI- или WSGI-сервер принимает сетевые соединения и передаёт запрос приложению; framework даёт маршрутизацию, доступ к параметрам, обработку ошибок и другие инструменты; handler — конкретная функция, выполняющая логику маршрута. В production также важны TLS/прокси, worker-процессы, timeouts, логи, конфигурация и управление ресурсами.

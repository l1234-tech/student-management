# Решение билета №4

## 1. Promise и async/await
Promise представляет результат асинхронной операции: pending, fulfilled или rejected. async-функция всегда возвращает Promise; await приостанавливает выполнение этой функции до результата и позволяет обрабатывать ошибку через try/catch. Асинхронность помогает не блокировать поток выполнения на ожидании ввода-вывода.

## 2. Синхронный и асинхронный Python
Синхронная операция обычно ждёт завершения текущего вызова. Асинхронный код с async/await позволяет event loop переключаться на другие задачи, пока операция ожидает ввода-вывода. Асинхронный код не делает автоматически CPU-вычисления быстрее; нужно использовать совместимые async-библиотеки.

## 3. Практика
~~~js
export async function loadStudents() {
  const response = await fetch("/api/students");
  if (!response.ok) throw new Error("HTTP " + response.status);
  return response.json();
}
~~~
Вызывающий код должен поймать ошибку через try/catch.

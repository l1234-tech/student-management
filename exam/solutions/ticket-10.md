# Решение билета №10

## 1. SPA
SPA загружает основную оболочку приложения и меняет отображаемое представление на клиенте без полной перезагрузки документа при каждом переходе. Клиентская маршрутизация связывает URL с компонентом/страницей.

## 2. Состояние
Локальное состояние нужно одному компоненту или небольшому поддереву. Глобальное состояние используется несколькими несвязанными частями приложения, например сведения о текущем пользователе.

## 3. Практика
Список может иметь состояния loading, error, empty и success. При загрузке показывается индикатор; при ошибке — понятное сообщение и возможность повторить запрос; при пустом результате — отдельное сообщение; при успехе — список. Состояния не должны отображаться одновременно противоречивым образом.

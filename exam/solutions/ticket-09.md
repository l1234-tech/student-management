# Решение билета №9

## 1. Аутентификация и авторизация
Аутентификация устанавливает личность пользователя; авторизация решает, разрешено ли ему действие.

## 2. JWT
JWT содержит claims и подпись. Подписанный токен не обязательно зашифрован: payload может быть прочитан. Access обычно предназначен для обращения к API и имеет меньший срок жизни; refresh используется для получения новых токенов по серверному контракту.

## 3. Практика
Backend должен аутентифицировать запрос и проверить разрешение на удаление. USER получает отказ, ADMIN может выполнить операцию при соблюдении остальных условий. Скрытие кнопки во frontend не защищает API, потому что HTTP-запрос можно отправить напрямую.

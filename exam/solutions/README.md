## Как читать билет

1. **Условия** приводятся из исходного файла «Рубежка №1.pdf» в исходной формулировке.
2. **Теория** сначала отвечает на поставленный вопрос прямо, а затем подробно раскрывает определения, причины, механизмы, сравнения и примеры.
3. **Практика** содержит решение кода, объяснение значимых строк, ожидаемое поведение и ограничения.
4. Если задача допускает несколько корректных реализаций, в решении указаны предположения и важные ограничения.

Формулировки условий взяты из PDF. Теоретические ответы и практические разборы — объяснения к этим условиям, а не дословный текст источника.

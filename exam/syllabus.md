## Шаблон ответа
1. Дай определение.
2. Объясни, какую проблему решает понятие.
3. Сравни с похожим термином.
4. Приведи пример.
5. Свяжи с лабораторной/файлом проекта, если связь действительно есть.

В ТЗ №4 указаны четыре возможных фреймворка и обязательный RxJS. Пока вариант неизвестен, не смешивай API разных фреймворков в одном примере.

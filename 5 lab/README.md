# Лабораторная №5 — Nuxt

Целевой стек для продолжения лабораторной №4: Nuxt поверх Vue. Здесь будет размещаться самостоятельная реализация метафреймворка.

## Требования

Сохранить функциональность лабораторной №4 и добавить SSR, динамический маршрут `/students/[id]`, route middleware, loading/error/404, кеширование и revalidation. Взаимодействие с Java-backend лабораторной №3 сохраняется; бизнес-логика и доступ к PostgreSQL остаются на backend.

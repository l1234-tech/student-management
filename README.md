# web2026-geeks

Сквозной учебный проект по веб-программированию: система управления студентами общежития.

## Структура репозитория

```text
1-2 lab/   лабораторные 1 и 2
3 lab/     заготовка для лабораторной 3
docs/      подробное описание реализации
```

## Лабораторные 1-2

Подробное описание реализации первой и второй лабораторных вынесено сюда:

```text
docs/labs-1-2.md
```

Кратко:

- Лабораторная 1: frontend без фреймворков, HTML/CSS/JS, CRUD студентов, cookies, клиентская валидация.
- Лабораторная 2: Django + Django REST Framework, REST API, JSON-хранилище, серверная валидация, фильтрация, stateless frontend.

## Лабораторная 3

Заготовка третьей лабораторной находится в папке:

```text
3 lab/
```

Там подготовлена архитектура под Spring Boot backend:

- REST API студентов;
- JPA/EclipseLink слой доступа к данным;
- JWT access/refresh авторизация;
- роли `ADMIN` и `USER`;
- DTO, service, repository, controller слои;
- Swagger/OpenAPI;
- пример `.env.example`;
- заготовка Bruno/Postman сценариев.

## Как запустить лабораторные 1-2

```powershell
cd "1-2 lab"
pip install -r requirements.txt
python manage.py runserver
```

Открыть:

```text
http://127.0.0.1:8000/
```

### Что важно знать о статусе

- Лабораторные 1–4 содержат реализации в соответствующих каталогах.
- Для лабораторной №5 сохранены требования и материалы подготовки; README каталога описывает текущий статус и не выдаёт за готовую реализацию отсутствующий код.
- Оригинальные PDF заданий хранятся отдельно от конспектов. Конспекты и ответы помогают готовиться, но не заменяют исходные формулировки преподавателя.

## Быстрый запуск

### Лабораторные 1–2 (Django)

Из корня репозитория:

```powershell
cd "1-2 lab"
python -m pip install -r requirements.txt
python manage.py runserver
```

Откройте http://127.0.0.1:8000. Дополнительное описание: [docs/labs-1-2.md](docs/labs-1-2.md).

### Лабораторная 3 (Spring Boot)

Подробные требования к окружению, настройкам PostgreSQL, переменным среды, API и тестам приведены в [README лабораторной №3](3%20lab/README.md). Для локального запуска используется скрипт `start.ps1` из каталога `3 lab`.

### Лабораторная 4 (Vue)

Команды локального запуска и Docker Compose приведены в [README лабораторной №4](4%20lab/README.md).

## История и исходные материалы

Проект перенесён из [geek-masters/web2026-geeks](https://sourcecraft.dev/geek-masters/web2026-geeks). Исходное описание сохранено в [docs/source-readme.md](docs/source-readme.md), включая сведения о командной работе.

Репозиторий предназначен для хранения учебных материалов и готовых реализаций лабораторных. Изменения основного командного проекта не следует автоматически переносить сюда целиком: в учебное хранилище добавляются только необходимые материалы и завершённые реализации.
